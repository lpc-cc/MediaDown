# 🎬 MediaDown — 视频/图片下载器

> 粘贴链接，即可下载抖音、TikTok、YouTube、Instagram 等 1700+ 平台的原画质视频与图片。

**Instagram 风格界面 · 一键启动 · 纯本地运行**

---

## ✨ 功能特点

- 🔗 **粘贴即用**：复制视频链接，粘贴到输入框，点击解析
- 📺 **1700+ 平台**：抖音、TikTok、YouTube、Instagram、Twitter/X、Facebook、Bilibili、Reddit、Pinterest 等
- 🎨 **原画质下载**：支持多画质选择，下载最高可用画质
- 💻 **纯本地运行**：无需联网注册，所有数据在本地处理
- 🎯 **极简操作**：双击 `start.bat` → 粘贴链接 → 下载

---

## 🚀 快速开始

### 前提条件

安装 **Python 3.9 或更新版本**：

1. 访问 [python.org](https://www.python.org/downloads/)
2. 下载并运行安装程序
3. ⚠️ **重要**：安装时勾选 **"Add Python to PATH"**（添加到系统路径）

### 启动应用

1. 双击项目根目录下的 **`start.bat`**
2. 首次运行会自动安装依赖（约 1-2 分钟），之后秒启动
3. 浏览器自动打开 `http://localhost:5000`

### 使用方法

1. 在抖音/TikTok/YouTube 等 App 中复制视频链接
2. 回到网页，点击 **📋** 按钮自动粘贴（或手动 Ctrl+V）
3. 点击 **"解析"** 按钮
4. 确认视频信息无误后，点击 **"⬇ 下载原画质"**
5. 文件自动保存到浏览器下载目录

关闭命令行窗口，或在窗口中按 `Ctrl + C`。

## 🔧 常见问题

**Q: 解析失败怎么办？**
A: 先确认链接是完整的（以 `http://` 或 `https://` 开头），且视频未删除/未设为私密。如果仍然失败，尝试更新 yt-dlp：

```bash
pip install -U yt-dlp
```

**Q: Instagram 视频无法下载？**
A: Instagram 部分内容需要登录。yt-dlp 支持配置 cookies，但本工具暂不内置此功能。

**Q: 下载速度慢？**
A: 下载速度取决于源平台服务器，与本工具无关。yt-dlp 已自动优化。

**Q: 下载的视频有水印？**
A: TikTok 等平台会在视频中嵌入水印，这是源平台的限制。
